# APEKS GNSS — Medusa

Medusa v2 обслуживает каталог, комплектации, корзины и заказы. Регион и цены — в рублях, каталог — на русском. Русский язык админки выбирается в профиле пользователя.

## Локально

Требуются Node.js 22.22+, PostgreSQL и Redis. Скопируйте `.env.example` в `.env`, задайте секреты и адрес базы, затем выполните:

```bash
npm ci
npx medusa db:migrate
npm run seed
npm run dev
```

`seed` выполняется один раз для пустой базы. Он создаёт регион России, бесплатные способы доставки, публичный ключ витрины и товары из `src/scripts/catalog.json`.

До подключения ЮKassa используется ручной платёжный провайдер. Он не списывает деньги; заказ требует ручного подтверждения и последующей оплаты через СБП.
