# APEKS GNSS — Backend (MedusaJS)

Данная директория предназначена для бэкенда интернет-магазина на **MedusaJS**.

## Задачи бэкенда:
- Управление каталогом товаров, остатками и категориями
- Управление корзиной и заказами
- Интеграция эквайринга (платежных шлюзов)
- API эндпоинты для фронтенда (Vue 3)
