# APEKS GNSS — frontend

Ветка `frontend` содержит Vue 3 витрину. GitHub Actions автоматически публикует её на https://nowa-nn.github.io/apeks-gnss/ после каждого коммита.

Товары, цены, корзины и заказы связаны с Medusa API на https://130.49.149.59. Русский каталог отображается на витрине; оплата через СБП будет подключена через ЮKassa позднее. До этого заказы оформляются с оплатой после подтверждения менеджером.

Локальный запуск: скопируйте `frontend/.env.example` в `frontend/.env`, укажите публичный ключ Medusa, затем `cd frontend && npm ci && npm run dev`.
