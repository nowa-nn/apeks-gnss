# APEKS GNSS — backend

Ветка `backend` содержит Medusa v2, русскоязычный каталог и конфигурацию развёртывания. Витрина находится в ветке `frontend` и публикуется через GitHub Pages.

Сервер проверяет обновления этой ветки каждые пять минут. Скрипт `deploy/apeks-update` собирает новый релиз, выполняет миграции и перезапускает Medusa. Файл с секретами хранится только на сервере: `/etc/apeks/medusa.env`.

Сейчас доступна ручная обработка заказов с последующей оплатой СБП. ЮKassa будет подключена позднее, после получения данных магазина и интеграции.
