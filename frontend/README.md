# APEKS GNSS — Vue 3 Версия (Точная копия Variant-2)

Проект переписан на **Vue 3** и **Vite** с сохранением **100% идентичности фронтенда, разметки, стилей и поведения с `variant-2`**.

## Решение проблемы с загрузкой CSS:
- В исходном варианте использовался клиентский CDN-скрипт `https://cdn.tailwindcss.com`, вызывавший эффект FOUC (мелькание элементов без стилей при первой загрузке).
- Во Vue 3 версии все классы Tailwind скомпилированы сборщиком Vite заранее в файл стилей `assets/index-[hash].css`, который подключен в `<head>` тегом `<link rel="stylesheet">`.
- Браузер парсит стили до отрисовки DOM, поэтому верстка отображается сразу с примененными стилями без каких-либо задержек.

## Структура для деплоя (`dist/`):
Папка `apeks-vue/dist/` полностью готова к размещению на веб-сервере:
```
apeks-vue/dist/
├── index.html        # Точка входа с относительными путями (base: './')
└── assets/           # Скомпилированные CSS, JS и все медиафайлы/картинки
```

## Запуск:
```bash
npm run dev     # Локальный сервер разработки (http://localhost:5173)
npm run build   # Сборка в папку dist/
```
